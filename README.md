# UI Design Using Qt Designer
In this project, the user interface (UI) has been designed using Qt Designer. The final result is an optimized interface, implemented and fully integrated with Python within the PyCharm development environment. This project is intended for engineers who have participated in the comprehensive control course offered by Powerliner and is provided as a fully open-source resource.
# طراحی UI با استفاده از QT Designer 
در این پروژه، رابط کاربری (UI) با استفاده از Qt Designer طراحی شده است. خروجی نهایی، یک رابط بهینه‌سازی‌شده است که در محیط توسعه PyCharm پیاده‌سازی و به‌طور کامل با زبان پایتون یکپارچه شده است. این پروژه برای مهندسانی در نظر گرفته شده که در دوره جامع کنترلِ ارائه‌شده توسط Powerliner شرکت کرده‌اند و به‌صورت یک منبع کاملاً متن‌باز (Open-source) در اختیار قرار می‌گیرد.
# نصب کتابخانه Tkinter  
برای اجرای این پروژه نیاز است که کتابخانه Tkinter نصب شده باشد که این کار روی فایل پروژه توسط بنده انجام شده است.اما درصورت بروز هرگونه مشکل و ارور مبتنی بر عدم نصب کتابخانه می‌توانید از طریق دستور pip install tkintertable این کتابخانه را به پروژه ی خود اضافه و نصب کنید.
