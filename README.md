# UI design using Tkinter
In this project, the UI is designed using Tkinter, resulting in an optimized user interface developed in Python within the PyCharm environment. This project is intended for engineers who have participated in the comprehensive control course offered by Powerliner; it is provided in its entirety as an open-source resource.
# طراحی UI با استفاده از Tkinter 
در این پروژه، رابط کاربری (UI) با استفاده از کتابخانه Tkinter طراحی شده است؛ بدین ترتیب، یک رابط کاربری بهینه در زبان پایتون و در محیط توسعه PyCharm ایجاد گردیده است. این پروژه برای مهندسانی در نظر گرفته شده که در دوره جامع کنترلِ ارائه‌شده توسط مجموعه (Powerliner) شرکت کرده‌اند و به‌طور کامل به عنوان یک منبع متن‌باز (Open-source) در دسترس قرار گرفته است.
# نصب کتابخانه Tkinter  
برای اجرای این پروژه نیاز است که کتابخانه Tkinter نصب شده باشد که این کار روی فایل پروژه توسط بنده انجام شده است.اما درصورت بروز هرگونه مشکل و ارور مبتنی بر عدم نصب کتابخانه می‌توانید از طریق دستور pip install tkintertable این کتابخانه را به پروژه ی خود اضافه و نصب کنید.
